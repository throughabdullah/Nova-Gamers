# CampusCoin

CampusCoin is a PHP 8 + MySQL student budget/expense management application.

## Run with XAMPP
1. Copy `campuscoin` to `C:\xampp\htdocs\campuscoin`.
2. Start **Apache** and **MySQL** in XAMPP.
3. Open `http://localhost/campuscoin/install.php` once.
4. Open `http://localhost/campuscoin/login.php`.
5. After installation, delete or rename `install.php`.

## Database
- Name: `campuscoin_db`
- Host: `localhost`
- User: `root`
- Password: empty by default in XAMPP
